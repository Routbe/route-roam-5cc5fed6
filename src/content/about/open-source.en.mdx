# Open source

ROUT source and the responsibilities of self-hosting.

## License

ROUT uses AGPL-3.0-or-later. Modified network services must comply with the corresponding source-access requirements. The actual license text takes precedence; this page is not legal advice.

## Inspect before running

Review code, dependencies and licenses before executing a downloaded project. Public source is not proof of an audit or security certification.

## Self-hosting needs operations

Maintain updates, secrets, database permissions, storage, mail, backups and incident handling. Never copy production credentials into a public repository.
