# Open source

Source ROUT et responsabilités de l’auto-hébergement.

## Licence

ROUT utilise AGPL-3.0-or-later. Les services réseau modifiés doivent respecter les obligations d’accès au code correspondant. Le texte de licence prévaut ; cette page n’est pas un avis juridique.

## Examiner avant d’exécuter

Vérifiez code, dépendances et licences avant d’exécuter un projet téléchargé. Une source publique ne prouve pas un audit ou une certification.

## Exploiter reste nécessaire

Gérez mises à jour, secrets, permissions, stockage, e-mail, sauvegardes et incidents. Ne copiez jamais de secrets de production dans un dépôt public.
