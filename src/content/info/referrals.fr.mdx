# Inviter des amis

Chaque membre dispose d'un lien d'invitation personnel. Toute personne qui s'inscrit via ce lien compte pour vos paliers.

## Votre lien

Les membres vérifiés partagent un lien avec leur propre nom, comme `rout.be/r/jouwnaam`. Les membres gratuits partagent un lien avec leur alias, afin que leur nom ne soit pas visible.

## Paliers

| Inscriptions | Récompense |
| --- | --- |
| 3 amis | 50 % de réduction |
| 3 amis vérifiés | Gratuit |
| 10 amis | Gratuit et le badge L'Influenceur |

Vous pouvez voir dans votre tableau de bord combien d'amis se sont inscrits et quel est votre prochain palier.

## Confidentialité

Vous voyez uniquement le nombre d'inscriptions, pas la liste des personnes qui se sont inscrites.
