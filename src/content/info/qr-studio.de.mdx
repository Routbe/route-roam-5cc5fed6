# QR Studio

Ein QR-Code ist ein lesbarer Verweis. Design und Ziel sind getrennte Entscheidungen: Ein schönes Muster muss immer noch zuverlässig scanbar sein.

## Auf deinem Gerät gestalten

Der Generator zeichnet den QR-Code lokal. Wähle deinen Inhalt, Stil und Kontrast und sieh dir den Code vor dem Export an. On-Device Smart Labels können den gewählten Inhalt begleiten, ohne dass dafür ein externer KI-Dienst erforderlich ist.

## Statisch oder dynamisch

Ein statischer Code enthält direkt den gewählten Inhalt. Dieser ändert sich nach dem Drucken nicht mehr. Ein dynamischer Code enthält einen verwalteten Link: Das Ziel wird vom Dienst verarbeitet und erfordert ein funktionierendes Deployment.

<Callout type="warning" title="Ein verwalteter Link bleibt vom Hosting abhängig">Ein lokal erstelltes Bild dient nicht als Ersatz für den Server hinter einem dynamischen Ziel. Überprüfe die echte Adresse, bevor du veröffentlichst.</Callout>

## SVG und Bilder

SVG eignet sich für eine skalierbare Vektordarstellung. Ein Rasterexport ist praktisch für Dokumente und Nachrichten. Canvas ist eine Zeichenmethode, keine separate Qualitätsgarantie: Das Format, die Ruhezone um den Code und der Kontrast bestimmen mit, ob Scanner ihn lesen können.

## Vom Bildschirm zum Druck

Teste den Export mit mehreren Smartphones und in der Größe, in der du ihn verwenden wirst. Behalte eine ruhige Ruhezone bei, vermeide zu geringen Kontrast und achte darauf, dass ein Logo den Code nicht unlesbar macht. Überprüfe nach dem Scannen auch das Ziel.

## Deinen Profilcode speichern

Speichere deinen Entwurf direkt aus dem aktiven Generator und überprüfe das veröffentlichte Profil. Beim Teilen werden die gespeicherten Einstellungen verwendet; eine nicht gespeicherte Änderung ist keine neue öffentliche Version.
