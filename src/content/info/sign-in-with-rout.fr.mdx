# Connexion avec ROUT

Votre ROUT ID est un compte unique qui vous permet de vous connecter à la fois à ROUT et à d'autres applications.

## Sans mot de passe

Les passkeys utilisent la sécurité de votre appareil : aucun mot de passe ne peut fuiter ou être victime de phishing. Pour les modifications irréversibles, telles que la fusion de comptes ou la modification du 2FA, ROUT demande un code à usage unique de six chiffres par e-mail.

## Se connecter à d'autres applications

Les applications et partenaires utilisent le standard ouvert OpenID Connect. La première fois, vous voyez quelles données une application demande et vous choisissez ce que vous partagez. Une application ne reçoit jamais plus que ce que vous autorisez.

## Autres moyens de se connecter

Vous pouvez également associer des comptes Google, Apple, Bluesky, Mastodon et d'autres services. Les comptes dont l'adresse e-mail n'a pas été confirmée par le fournisseur ne sont associés qu'après validation d'un code reçu par e-mail, empêchant ainsi quiconque de saisir votre adresse pour s'approprier votre compte.
