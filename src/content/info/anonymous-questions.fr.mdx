# Utiliser les questions anonymes

Recevez des questions sur votre profil ou via une page de questions dédiée. Vous choisissez vous-même qui peut vous écrire et quelles réponses vous publiez.

## Activer la réception des questions

Ouvrez [Studio](/studio) pour le profil que vous souhaitez modifier. La réception des questions est désactivée par défaut. Dans les paramètres des questions, activez **Accepter les messages** et choisissez votre public cible :

- **Tout le monde** : les visiteurs peuvent écrire sans compte ROUT, sauf si des restrictions plus strictes s'appliquent.
- **Membres ROUT uniquement** : l'expéditeur doit être connecté.
- **Membres ROUT vérifiés uniquement** : un compte connecté et vérifié est requis.

Même si un compte est nécessaire, les détails du compte ne sont pas montrés au destinataire. Pour en savoir plus sur les limites, consultez [Anonymat & sécurité](/safety/anonymous-questions).

## Bloc de profil ou page de questions dédiée

Un bloc de questions se trouve sur le profil hub où vous l'ajoutez. Vous souhaitez un lien distinct ? Activez alors la **Page de questions anonymes** dans le Studio sous **Paramètres** ; sur cette page, vous personnalisez uniquement le design, ainsi que l'affichage de votre photo de profil et d'un bouton vers votre profil principal. Un profil personnel utilise `/<nom>/ask` ; un alias de confidentialité utilise `/u/<alias>/ask`.

La page dédiée propose des réglages pour le design, la photo de profil et un lien vers le profil principal. Ce n'est pas un second profil hub librement personnalisable. Le formulaire de question et les réponses peuvent être mis en forme séparément.

## Enregistrer n'est pas publier

**Enregistrer** conserve votre brouillon dans Studio. Seul **Publier** rend publics les paramètres de profil modifiés et le design. Vérifiez ensuite le lien de questions du bon profil. Les choix pour votre profil personnel ne modifient pas automatiquement ceux de votre alias de confidentialité.

## Envoyer un message

1. Ouvrez le bloc de questions ou le lien de questions du destinataire.
2. Rédigez un message de maximum **300 caractères**. Le dé donne une idée ; il n'envoie rien.
3. Utilisez éventuellement le [Ghost Mode](/info/ghost-mode) et vérifiez la proposition.
4. Choisissez **Envoyer anonymement** lorsque vous êtes satisfait.

N'envoyez pas de noms, de coordonnées ou de détails personnels que vous ne souhaitez pas partager. Un nom d'expéditeur masqué ne rend pas un contenu reconnaissable méconnaissable.

## Si l'envoi ne fonctionne pas

Une page fermée n'accepte pas de questions. Un public restreint peut nécessiter que vous soyez connecté ou vérifié. Une limite de **cinq messages par minute** et **vingt par heure par adresse IP** s'applique ; sur un réseau partagé, vous partagez ces limites avec d'autres visiteurs.

Une confirmation d'envoi n'est pas un accusé de lecture ni une garantie de réponse. Les messages d'expéditeurs mis en sourdine ou temporairement bloqués peuvent recevoir la même confirmation sans apparaître dans la boîte de réception.

## Questions et réponses ne sont pas un livre d'or

Le [livre d'or](/info/guestbook) est une fonctionnalité distincte pour les notes laissées par des membres vérifiés. Les questions anonymes disposent de leur propre boîte de réception et ne deviennent publiques qu'après une publication explicite accompagnée d'une réponse.

Poursuivez avec [Réponses & stories](/info/answers-and-stories) ou découvrez [pourquoi ROUT propose des questions anonymes](/about/anonymous-questions).
