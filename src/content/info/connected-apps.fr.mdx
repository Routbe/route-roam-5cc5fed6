# Apps connectées

Quand vous vous connectez avec ROUT, vous décidez ce que l'app reçoit. Vous le voyez à l'avance sur l'écran de consentement et pouvez le retirer ensuite.

## Ce qu'une app peut voir

- Un code propre à vous, valable uniquement pour cette app.
- Votre nom et votre photo, si vous l'autorisez.
- L'adresse e-mail choisie : la vraie ou un relais privé.
- Une preuve supplémentaire, comme « humain réel », seulement après votre accord séparé.

## Ce qu'une app ne voit jamais

- Vos autres comptes, comme Google ou GitHub.
- Les autres apps que vous utilisez.
- Vos clés de paiement, documents ou alias anonymes.
- Votre code chez une autre app : deux apps ne peuvent pas vous relier.

## Garder le contrôle

Dans Compte et sécurité, vous voyez les apps connectées et ce qu'elles ont reçu. Vous pouvez déconnecter une app ou transmettre une nouvelle adresse uniquement aux apps cochées. Lisez aussi [pourquoi ROUT ne partage pas de listes](/info/no-account-lists).
