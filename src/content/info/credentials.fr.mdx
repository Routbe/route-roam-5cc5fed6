# Credentials

Badges, certificats et diplômes : origine, signification et visibilité.

<Callout type="info" title="Ce qui existe actuellement">
Le code source contient des règles de stockage et un affichage public pour les credentials d'applications. Une API d'émission externe et un contrôle complet de l'acceptation ne sont pas encore disponibles en tant que service vérifié.
</Callout>

## Une section dédiée par application

Sur un profil public, les credentials publiés peuvent être regroupés sous le nom de l'application. Ainsi, l'origine d'un diplôme, d'un certificat ou d'un badge reste identifiable. Ouvrez un élément pour consulter la description et le profil de l'émetteur, s'ils sont disponibles.

| Type | Déclaration de l'émetteur | Aucune garantie automatique |
| --- | --- | --- |
| Badge | Par exemple, participation ou adhésion | Contrôle d'identité officiel |
| Certificat | Par exemple, formation suivie | Accréditation reconnue |
| Diplôme | Par exemple, qualification obtenue | Validité pour une profession réglementée |

## La publication est un choix distinct

Un élément reçu n'a pas vocation à se retrouver automatiquement sur le web. La projection publique nécessite une acceptation, un profil public, une section d'application publiée et une autorisation active de l'application. Les éléments révoqués n'apparaissent pas dans l'affichage public. De plus, un badge à côté de votre nom fait l'objet d'un choix d'affichage distinct.

Lorsqu'une application est masquée, cela s'applique à tous les credentials de cette section. Une capture d'écran publique ne peut pas être récupérée ; ne publiez donc pas de qualifications sensibles ou de données personnelles sans un choix délibéré.

## Que signifie « vérifiable » ?

Un titre, une image et une date d'émission ne constituent pas encore une preuve cryptographique. La structure actuelle des credentials d'application n'est pas une implémentation complète des W3C Verifiable Credentials. La vérification des signatures, des formats de preuve externes et des listes de révocation nécessite des protocoles supplémentaires.

## Si un credential est incorrect

Pour le contenu, contactez l'émetteur. ROUT peut restreindre la visibilité publique, mais ne décide pas pour autant si une formation est reconnue. N'utilisez jamais un badge comme seule preuve d'accès, de paiement ou d'habilitation légale.
