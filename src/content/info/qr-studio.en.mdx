# QR Studio

A QR code is a readable reference. Design and destination are separate choices: an attractive pattern still needs to be reliably scannable.

## Designing on your device

The generator renders the QR code locally. Choose your content, style, and contrast, and preview the code before you export. On-device Smart Labels can accompany the chosen content without requiring an external AI service.

## Static or dynamic

A static code directly contains the chosen content. It does not change once you print it. A dynamic code contains a managed link: the destination is handled by the service and requires an active deployment.

<Callout type="warning" title="A managed link remains dependent on hosting">A locally generated image does not replace the server behind a dynamic destination. Check the actual address before you publish.</Callout>

## SVG and images

SVG is suitable for scalable vector display. A raster export is handy for documents and messages. Canvas is a rendering method, not a standalone guarantee of quality: the size, the quiet zone around the code, and contrast all help determine whether scanners can read it.

## From screen to print

Test the export with multiple phones and at the actual size you plan to use it. Maintain a clear quiet zone, avoid low contrast, and do not let a logo make the code unreadable. Also verify the destination after scanning.

## Saving your profile code

Save your design from the active generator and check the published profile. Sharing uses the saved settings; an unsaved change is not a new public version.
