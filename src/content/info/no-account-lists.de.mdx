# Warum ROUT keine Listen teilt

Viele Anmeldedienste geben Apps eine Liste deiner verknüpften Accounts. ROUT tut das nie, auch nicht auf Anfrage.

## Das Problem mit Listen

Eine Liste wie „Google, GitHub, Discord“ wirkt harmlos. Doch jede App, die sie erhält, kann dich dienstübergreifend verfolgen, Profile bauen oder Daten verkaufen. Ein Leck genügt.

## Wie ROUT es löst

Eine App, die dich schon kennt, sendet verschlüsselte Fingerabdrücke dessen, was sie bereits weiß, etwa deine E-Mail-Adresse. Dein eigener Browser vergleicht sie. Passt etwas, fragt ROUT dich, ob du genau diese eine Verknüpfung bestätigen willst. Nur dieses eine Detail geht an die App, und nur mit deinem Ja.

## Was das für dich bedeutet

- Eine App erfährt nichts, was sie nicht schon wusste.
- Sagst du nein, merkt die App nicht einmal, dass es einen Treffer gab.
- ROUT speichert die Fingerabdrücke nicht.
