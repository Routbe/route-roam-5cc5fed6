# Inscription à la newsletter

Avec le bloc d'inscription, les visiteurs peuvent laisser leur adresse e-mail sur votre profil.

## Ajouter

Dans l'éditeur, ajoutez le bloc d'inscription à votre profil. Dans les paramètres du bloc, vous pouvez voir combien de personnes se sont inscrites et combien d'entre elles ont confirmé leur adresse.

## Connexion avec Brevo

Si vous utilisez Brevo, vous pouvez associer une liste. Les nouvelles inscriptions seront alors également envoyées vers cette liste.

## Télécharger les adresses

Vous seul pouvez télécharger la liste sous forme de fichier CSV. Par défaut, vous n'obtenez que les adresses confirmées. Les adresses sont stockées sous forme chiffrée et déchiffrées uniquement pour ce téléchargement. Vous ne pouvez pas effectuer de téléchargements successifs de manière illimitée.

## Désinscription

Chaque destinataire peut se désinscrire à tout moment via le lien présent dans l'e-mail.
