# Vrienden uitnodigen

Elk lid heeft een persoonlijke uitnodigingslink. Wie zich via die link aanmeldt, telt mee voor jouw mijlpalen.

## Je link

Geverifieerde leden delen een link met hun eigen naam, zoals `rout.be/r/jouwnaam`. Gratis leden delen een link met hun alias, zodat hun naam niet zichtbaar wordt.

## Mijlpalen

| Aanmeldingen | Beloning |
| --- | --- |
| 3 vrienden | 50% korting |
| 3 geverifieerde vrienden | Gratis |
| 10 vrienden | Gratis en de badge De Influencer |

Je ziet in je dashboard hoeveel vrienden zich hebben aangemeld en wat je volgende mijlpaal is.

## Privacy

Je ziet alleen aantallen, geen lijst met wie zich heeft aangemeld.
