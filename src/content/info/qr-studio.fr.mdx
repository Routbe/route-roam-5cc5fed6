# QR Studio

Un QR code est une référence lisible. Le design et la destination sont des choix distincts : un motif élégant doit toujours pouvoir être scanné de manière fiable.

## Concevoir sur votre appareil

Le générateur crée le QR code localement. Choisissez votre contenu, votre style et votre contraste, puis prévisualisez le code avant de l'exporter. Des Smart Labels intégrés sur l'appareil peuvent accompagner le contenu sélectionné sans nécessiter de service d'IA externe.

## Statique ou dynamique

Un code statique contient directement le contenu choisi. Celui-ci ne change pas après impression. Un code dynamique contient un lien géré : la destination est prise en charge par le service et nécessite un déploiement fonctionnel.

<Callout type="warning" title="Un lien géré reste dépendant de l'hébergement">Une image créée localement ne remplace pas le serveur associé à une destination dynamique. Vérifiez l'adresse réelle avant de publier.</Callout>

## SVG et images

Le format SVG convient parfaitement pour un rendu vectoriel évolutif. Un export matriciel est pratique pour les documents et les messages. Canvas est une méthode de rendu, pas une garantie distincte de qualité : la taille, la marge autour du code et le contraste déterminent en partie si les scanners peuvent le lire.

## De l'écran à l'impression

Testez l'export avec plusieurs téléphones et à la taille réelle d'utilisation. Conservez une marge de sécurité dégagée, évitez les contrastes trop faibles et veillez à ce qu'un logo ne rende pas le code illisible. Vérifiez également la destination après le scan.

## Sauvegarder votre code de profil

Enregistrez votre design depuis le générateur actif et vérifiez le profil publié. Le partage utilise les paramètres enregistrés ; une modification non sauvegardée ne constitue pas une nouvelle version publique.
