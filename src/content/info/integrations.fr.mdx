# Intégrations

Dans le Connections Hub, vous associez les plateformes sur lesquelles vous êtes actif. Pour chaque connexion, vous choisissez si elle apparaît sur votre profil professionnel, social ou les deux.

## Ce que vous pouvez associer

| Catégorie | Exemples |
| --- | --- |
| Musique et vidéo | Spotify (en cours d'écoute), carte de chaîne YouTube |
| Réseaux sociaux | Bluesky, Mastodon, Snapchat, Instagram, TikTok, X, LinkedIn, Discord, Twitch |
| Code et travail | GitHub, GitLab, WakaTime |
| Jeux et apprentissage | Chess.com, Lichess, Duolingo |
| Publication et paiement | RSS, Lightning, Monero, Ethereum |

## Des chiffres authentiques

Votre portée totale ne comptabilise que les comptes que vous avez réellement associés : les plateformes ouvertes sont récupérées automatiquement, les autres sont renseignées pour chaque connexion. Aucun chiffre estimé ou gonflé.

## Confidentialité

Les jetons sont conservés chiffrés sur le serveur et ne sont jamais envoyés au navigateur. Les visiteurs consultent des cartes mises en cache, de sorte que leur adresse IP ne parvient jamais au service externe. La déconnexion révoque l'accès et supprime les données.
