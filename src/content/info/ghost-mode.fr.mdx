# Mode Ghost : neutraliser votre style d'écriture

Le choix de vos mots peut vous rendre reconnaissable. Le Mode Ghost vous propose, sur demande, une version plus neutre de votre message, que vous pouvez d'abord évaluer vous-même.

## Comment fonctionne la réécriture

1. Rédigez votre question ou message.
2. Cliquez sur l'icône en forme d'étoiles à côté du champ de message.
3. Lisez la proposition qui apparaît dans ce même champ. Vérifiez le sens, le ton et les détails personnels.
4. Modifiez-la ou choisissez **Rétablir l'original** pour restaurer votre texte d'avant la réécriture.
5. N'envoyez le message que si vous le souhaitez.

La réécriture est facultative. Rétablir l'original n'envoie rien. Le destinataire peut voir un indicateur de style sur un message réécrit ; ce n'est pas une preuve que le texte est méconnaissable.

## La même langue, mais pas nécessairement la même nuance

L'IA a pour consigne de conserver le message principal et de rester dans la même langue. L'argot, les dialectes, les fautes de frappe, les émojis excessifs et les habitudes d'écriture caractéristiques peuvent être neutralisés. Pour les textes très courts ou peu clairs, la langue du site peut servir d'indice.

Un modèle peut altérer le sens ou mal évaluer la langue. Le filtre de base comprend moins le contexte. Vérifiez donc toujours une proposition, même si elle semble bien formulée.

## Ce qui est traité

En lançant la réécriture, vous faites traiter le texte saisi par la fonction de réécriture de ROUT et, lorsqu'il est disponible, par le service d'IA externe configuré. Infomaniak AI Tools est la configuration par défaut ; un autre service peut être défini. La requête contient le texte, les instructions de réécriture et, si nécessaire, une indication de langue, mais pas l'intégralité de votre boîte de réception ni votre profil ROUT.

L'original reste accessible dans le formulaire pour restauration et n'est pas enregistré comme une seconde question dans la boîte de réception. La fonction de réécriture de ROUT n'enregistre pas le texte du message dans ses journaux. N'en déduisez pas une promesse générale concernant le traitement ou les durées de conservation d'un service externe.

## Si le service ne répond pas

Un filtre simple basé sur des règles peut être utilisé lorsqu'aucune réponse exploitable du modèle n'est disponible. La notification accompagnant votre message l'indique clairement. Si la requête échoue complètement, votre texte reste inchangé ; vous pouvez continuer à écrire vous-même ou réessayer plus tard.

Une limite de **trois réécritures par minute** et **vingt par heure par adresse IP** s'applique. La réécriture et l'envoi de messages disposent de compteurs distincts.

## Ce que le Mode Ghost ne peut pas promettre

Le Mode Ghost ne dissimule pas votre identité, ne supprime pas de manière infaillible toutes les données personnelles et ne garantit pas l'anonymat. Il ne répond pas à votre question et ne valide pas un message comme étant sûr. N'inscrivez pas de données sensibles dans le texte dans l'espoir de les faire supprimer par l'IA.
