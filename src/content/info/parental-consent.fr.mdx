# Consentement parental pour les moins de 16 ans

Vous avez moins de 16 ans ? ROUT demande alors le consentement d'un parent ou tuteur légal avant que votre compte ne soit pleinement opérationnel. Nous respectons ainsi les règles européennes de protection de la vie privée (RGPD) et assurons la sécurité des jeunes membres.

## Comment cela fonctionne

1. Lors de la création de votre compte, vous renseignez votre date de naissance.
2. Si vous avez moins de 16 ans, ROUT demande l'adresse e-mail de votre parent ou tuteur.
3. Votre parent reçoit un e-mail contenant un lien personnel à usage unique.
4. Grâce à ce lien, votre parent donne son consentement et choisit qui peut vous envoyer des messages.
5. Votre compte devient ensuite opérationnel. Votre parent peut modifier les paramètres ultérieurement via ce même lien.

## Ce que votre parent peut gérer

- **Consentement** : sans consentement, votre compte reste limité.
- **Qui peut vous envoyer des messages** : désactivé, comptes vérifiés uniquement, tous les membres de ROUT ou tout le monde. Par défaut, seuls les comptes vérifiés y sont autorisés.
- **Paiements** : si vous souhaitez effectuer un achat, la demande est envoyée à votre parent. Celui-ci dispose de 48 heures pour régler ; passé ce délai, la demande expire.

## Vie privée pour vous et votre parent

- Le lien dans l'e-mail est la clé d'accès de votre parent. ROUT n'en conserve qu'une empreinte chiffrée, jamais le lien lui-même.
- Votre parent ne voit pas vos messages, vos réponses ni vos visiteurs.
- Nous utilisons uniquement l'adresse e-mail de votre parent pour le consentement et les paiements, jamais à des fins publicitaires.
- À vos 16 ans, le contrôle parental prend fin automatiquement.
