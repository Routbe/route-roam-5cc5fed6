# Integrationen

Im Connections Hub verbindest du die Orte, an denen du aktiv bist. Für jede Verknüpfung wählst du aus, ob sie auf deinem beruflichen, sozialen oder auf beiden Profilen angezeigt wird.

## Was du verbinden kannst

| Kategorie | Beispiele |
| --- | --- |
| Musik und Video | Spotify (hört gerade), YouTube-Kanalkarte |
| Soziale Netzwerke | Bluesky, Mastodon, Snapchat, Instagram, TikTok, X, LinkedIn, Discord, Twitch |
| Code und Arbeit | GitHub, GitLab, WakaTime |
| Spiele und Lernen | Chess.com, Lichess, Duolingo |
| Veröffentlichen und Bezahlen | RSS, Lightning, Monero, Ethereum |

## Ehrliche Zahlen

Deine Gesamtreichweite zählt nur Konten, die du tatsächlich verknüpft hast: Offene Plattformen werden automatisch abgerufen, andere trägst du pro Verknüpfung ein. Keine geschätzten oder künstlich aufgeblähten Zahlen.

## Datenschutz

Tokens werden verschlüsselt auf dem Server gespeichert und niemals an den Browser gesendet. Besucher rufen zwischengespeicherte Karten ab, sodass ihre IP-Adresse nicht beim externen Dienst landet. Das Trennen der Verbindung widerruft den Zugriff und löscht die Daten.
