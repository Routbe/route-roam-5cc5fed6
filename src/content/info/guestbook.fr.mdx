# Livre d'or

Avec le livre d'or, les autres membres peuvent laisser un court mot sur votre profil.

## Qui peut écrire

Uniquement les membres connectés et vérifiés qui ne sont pas bloqués. Cela permet d'éviter les spams.

## Ce que voient les visiteurs

Uniquement les messages que vous épinglez, et seulement si votre profil est public.

## Gestion

Vous pouvez épingler ou supprimer n'importe quel message sur votre propre profil.
